# 1 接口

接口是引用数据类型，是规范和标准。

接口只定义要做什么，不定义怎么做。谁实现这个接口，谁就必须按这个规则来。

简单说，接口只定规则，实现类负责干活。

## 1.1 接口关键字

### 1.1.1 `interface`

```java
public interface 接口名 {}
```

### 1.1.1 `implements`

```java
public class 类名 implements 接口名 {}
```

## 1.2 接口中可定义的成员概述

### 1.2.1 JDK7 以及之前的接口成员

JDK7 及更早版本，也是接口最原始的规则，只能定义抽象方法和成员变量

#### 抽象方法

在接口里写普通方法，即使不手写 `public abstract` 这两个关键字，编译后也会被自动加上

```java
void test(); // 写在接口里的普通方法

public abstract void test(); // 实际编译后，会自动加上 public abstract
```

接口里的抽象方法没有方法体，必须由实现接口的类重写。

#### 成员变量

接口里定义的变量，即使不写 `public static final` 这仨，也会被自动补全。

`final` 代表变量初始化后就不能被二次修改，所以接口里的变量本质都是常量。

```java
int NUM = 10; // 写在接口里的成员变量

public static final int Num = 10; // 实际编译后，会自动加上 public static final
```

### 1.2.2 JDK8 新增的接口成员

为了让接口扩展功能时，不用强制所有实现类重写方法，新增了两种带方法体的方法：

#### 默认方法

默认方法通过在 `public` 后面添加 `default` 来实现，并且有方法体。

默认方法可重写，也可不重写。

```java
public default void work() {
    System.out.println("默认方法逻辑");
}
```

**注意：** 默认方法的 `default` 只能在接口中使用，在类型使用会报错

```java
public class Test {
    public default void fn() {} // 这种写法是不正确的，会报错。
}
```

#### 静态方法

接口静态方法的定义方式和类的静态方法的定义方式一样，使用方式是通过 `接口名.静态方法()` 来调用，有方法体。

实现类不会继承接口静态方法。

```java
public static void staticWork() {
    System.out.println("接口静态方法");
}
```

### 1.2.3 JDK9 及之后新增的接口成员

#### 私有方法

JDK9 允许在接口里定义 `private` 私有方法（分私有实例方法、私有静态方法）

```java
// 接口私有实例方法
private void innerLogic() {}

// 接口私有静态方法
private static void staticInnerLogic() {}
```

**注意：**

- 只能在接口**内部**调用，用来抽取默认方法、静态方法里重复的公共代码；
- 接口的实现类无法访问、重写这些私有方法

## 1.3 接口的使用

- 定义接口
- 实现类实现接口
- 重写接口中的抽象方法
- 创建实现类对象（因为接口不能 new 对象，只能通过实现类去 new 对象）
- 通过实现类对象调用重写的方法

```java
package com.testing.oop2.Interface;

public class Demo01Test {
    public static void main(String[] args) {
        Mouse m = new Mouse();
        m.open();
        m.close();
    }
}

interface Usb {
    public abstract void open();

    public abstract void close();
}

class Mouse implements Usb {
    @Override
    public void open() {
        System.out.println("插入鼠标");
    }

    @Override
    public void close() {
        System.out.println("关闭鼠标");
    }
}

/*
插入鼠标
关闭鼠标
*/
```

## 1.4 接口中成员的使用

### 1.4.1 抽象方法

#### 定义格式

```java
public abstract 返回值类型 方法名(形参);
```

#### 注意事项

- 即使不写 `public abstract`，默认也会被加上；
- 抽象方法没有方法体

#### 具体使用

```java
package com.testing.oop2.Interface;

public class Demo02Test {
    public static void main(String[] args) {
        Keyboard k = new Keyboard();
        String open = k.open();
        System.out.println(open);
        String close = k.close();
        System.out.println(close);
    }
}

interface Usb2 {
    public abstract String open();

    String close();
}

class Keyboard implements Usb2 {
    @Override
    public String open() {
        return "键盘接入成功！";
    }

    @Override
    public String close(){
        return "键盘成功拔掉！";
    }
}

/*
键盘接入成功！
键盘成功拔掉！
*/
```

### 1.4.2 成员变量

#### 定义格式

```java
public static final 数据类型 变量名 = 值;
```

#### 注意事项

- 被 `final` 关键字修饰的变量，不能再次被赋值，所以可以视为常量；
- `final` 修饰的变量初始化时，必须赋值，否则报错（首次不赋值，后面不可以赋值了）；
- `final` 修饰的变量，变量名默认约定为全大写；
- `public static final` 此三个关键字就算不写也会自动加在接口的成员变量中

#### 具体使用

```java
package com.testing.oop2.Interface;

public class Demo05Test {
    public static void main(String[] args) {
        System.out.println("NUM_1==" + USB05.NUM_1);
        System.out.println("NUM_2==" + USB05.NUM_2);
    }
}

interface USB05 {
    static final Number NUM_1 = 100;
    Number NUM_2 = 200;
    // Number NUM_3; // 会报错：字段 'NUM_3' 可能尚未初始化
}

/*
NUM_1==100
NUM_2==200
*/
```

### 1.4.3 默认方法

#### 定义格式

```java
public default 返回值类型 方法名(形参) {
    方法体;
    return 结果;
};
```

#### 注意事项

- 默认方法可重写，可不重写；
- 默认方法有方法体；
- 在实现类重写默认方法时，`default` 关键字记得去掉，此关键字只在接口中支持定义在方法上，类型不支持。

#### 具体使用

```java
package com.testing.oop2.Interface;

public class Demo03Test {
    public static void main(String[] args) {
        Mouse03 m3 = new Mouse03();
        m3.fnDef();

        Keyboard03 k3 = new Keyboard03();
        k3.fnDef();
    }
}

interface Use {
    public default void fnDef() {
        System.out.println("我是 Use 接口中的默认方法");
    }
}

class Mouse03 implements Use { }

class Keyboard03 implements Use {
    @Override
    public void fnDef() {
        System.out.println("我是重写了 Use 接口中 fnDef 的方法");
    }
}

/*
我是 Use 中的默认方法
我是重写了 Use 接口中 fnDef 的方法
*/
```

### 1.4.4 静态方法

#### 定义格式

```java
public static 返回值类型 方法名(形参) {
    方法体;
    return 结果
}
```

#### 注意事项

- 静态方法不支持重写；
- 直接通过接口名调用。

#### 具体使用

```java
package com.testing.oop2.Interface;

public class Demo04Test {
    public static void main(String[] args) {
        USB4.fnStatic();
        DevUtil.fnStatic();
    }
}

interface USB4 {
    public static void fnStatic() {
        System.out.println("接口中的静态方法 fnStatic");
    }
}

class DevUtil implements USB4 {
    // @Override  // 这里如果用上 @Override 会报错
    public static void fnStatic() {
        System.out.println("实现类中的 fnStatic 静态方法");
    }
}

/*
接口中的静态方法 fnStatic
实现类中的 fnStatic 静态方法
*/
```

### 默认和静态方法应用场景

当需要在 **已被多个类实现的接口** 中加某些小功能时，就可以用上默认方法和静态方法，这两种方法不需要被重写，可以兼容现有代码。

## 1.5 接口的特点

- 接口可以多继承（一个接口可以继承多个接口）

  ```java
  public interface InterfaceA extends InterfaceB, InterfaceC {}
  ```

- 接口可以多实现（一个类可以实现一个或多个接口）

  ```java
  public class ImplCls extends InterfaceA, InterfaceB {}
  ```

- 一个类可以在继承父类的同时实现一个或多个接口

  ```java
  public class Child extends Parent implements InterfaceA, InterfaceB {}
  ```

**注意：**

- 只要父类或接口中存在抽象方法，子类或实现类都必须重写该方法
- 当一个类实现多个接口时，这些接口如果都存在重名且参数一样的抽象方法，实现类只需重写一次即可

  ```java
  interface InterfaceA {
      void fn();
  }

  interface InterfaceB {
    public abstract void fn();
  }

  class ImplCls implements InterfaceA, InterfaceB {
    @Override
    public void fn() {};
  }
  ```

- 当一个类实现多个接口时，这些接口如果都存在重名且参数一样的默认方法，实现类必须重写一次默认方法

  ```java
  interface InterfaceA1 {
      public default void fn() {}
  }

  interface InterfaceB1 {
      public default void fn() {}
  }

  class ImplCls02 implements InterfaceA1, InterfaceB1 {
      @Override
      public void fn() {}
  }
  ```

## 1.6 接口和抽象类的区别

### 相同点

- 都位于继承体系的顶端，用于被其他类继承、实现；
- 都不能 `new`；
- 都包含 `abstract` 方法，其子类或实现类都必须重写这些抽象方法。

### 不同点

- 抽象类一般作为父类使用，可以有成员变量、成员方法、构造方法和抽象方法；
- 接口成员单一，一般都是方法的集合，也可以视为功能的集合；
- 抽象类不能多继承，但接口可以多实现。

# 2 多态

多态的实现需要满足三个条件：

- 必须有子父类继承或接口实现关系；
- 必须有方法的重写
- 父类引用指向子类对象

  ```java
  Parent obj = new Child()
  // 可以理解为大类型接收了一个小类型的数据，如：double num = 10
  ```

  ```java
  package com.testing.oop2.Polymorphic.DemoTest01;

  public abstract class Animal {
      public abstract void eat();
  }
  ```

  ```java
  package com.testing.oop2.Polymorphic.DemoTest01;

  public class Dog extends Animal {
      public void eat() {
          System.out.println("Dogs eat bones");
      }

      public void look (){
          System.out.println("Dog guarding the house");
      }
  }
  ```

  ```java
  package com.testing.oop2.Polymorphic.DemoTest01;

  public class Cat extends Animal {
      public void eat() {
          System.out.println("The cat is eating cat food");
      }

      public void catchMouse() {
          System.out.println("Catch the mouse");
      }
  }
  ```

  ```java
  package com.testing.oop2.Polymorphic.DemoTest01;

  public class DemoTest01 {
      public static void main(String[] args) {
          Animal d = new Dog();
          d.eat();
          // d.look(); // 报错：无法解析 'Animal' 中的方法 'look'

          Animal c = new Cat();
          c.eat();
          // c.catchMouse(); // 无法解析 'Animal' 中的方法 'catchMouse'
      }
  }

  /*
  Dogs eat bones
  The cat is eating cat food
  */
  ```

## 2.1 多态下成员的访问特点

### 2.1.1 成员变量

多态中，成员变量（或静态方法）看引用类型（父类类型），不看实际 new 的子类对象。

```java
package com.testing.oop2.Polymorphic.DemoTest02;

public class Parent {
    int num = 1000;
}
```

```java
package com.testing.oop2.Polymorphic.DemoTest02;

public class Child extends Parent {
    int num = 100;
}
```

```java
package com.testing.oop2.Polymorphic.DemoTest02;

public class DemoTest02 {

    }

/*
num==1000
*/
```

### 2.1.2 成员方法

成员方法看实际 new 的子类对象，先在子类找，子类没有就往上找父类。

```java

public class Parent {
    public void fn(){

```

```java
package com.testing.oop2.Polymorphic.DemoTest02;

    }
}
```

```java

Child 的 fn 方法
*/
```

## 2.2 多态的好处

**思考：**

使用原始的 new 对象方式（变量类型和 new 的类一样）创建的对象，可以使用重写的方法、继承的方法以及自身特有的成员。

使用多态方式 new 对象，却只能使用重写的方法，而不能使用子类特有成员，那为啥还要使用多态？

### 多态 new 和原始 new 对比

原始 new 方式：

- 优点：可以使用重写方法、自己特有以及父类非私有变量和方法
- 缺点：扩展性差

```java
package com.testing.oop2.Polymorphic.DemoTest03;

public abstract class Animal {
    public abstract void eat();
}
```

```java
package com.testing.oop2.Polymorphic.DemoTest03;

public class Dog extends Animal {
    public void eat() {
        System.out.println("Dogs eat bones");
    }

    public void look (){
        System.out.println("Dog guarding the house");
    }
}
```

```java
package com.testing.oop2.Polymorphic.DemoTest03;

public class Cat extends Animal {
    public void eat() {
        System.out.println("The cat is eating cat food");
    }

    public void catchMouse() {
        System.out.println("Catch the mouse");
    }
}
```

```java
package com.testing.oop2.Polymorphic.DemoTest03;

public class DemoTest03 {
    public static void main(String[] args) {
        DemoTest03 demoTest03 = new DemoTest03();
        Dog d = new Dog();
        demoTest03.fnDog(d);
        Cat c = new Cat();
        demoTest03.fnCat(c);
        // 原始的 new 方式，会导致如果要在方法中使用继承自 Animal 的子对象中的同名方法，就得创建多个方法，并让形参的类型为该子对象类型
        // 这样方式的扩展性很差
    }

    public void fnDog(Dog d){
        d.eat();
        d.look(); // 可以使用子对象自身特有方法
    }

    public void fnCat(Cat c){
        c.eat();
        c.catchMouse(); // 可以使用子对象自身特有方法
    }

    // ...
}

/*
Dogs eat bones
The cat is eating cat food
*/
```

多态 new 方式：

- 优点：扩展性强
- 缺点：不能调用子类对象特有方法

```java
package com.testing.oop2.Polymorphic.DemoTest04;

public abstract class Animal {
    public abstract void eat();
}
```

```java
package com.testing.oop2.Polymorphic.DemoTest04;

public class Dog extends Animal {
    public void eat() {
        System.out.println("狗吃狗粮");
    }

    public void look (){
        System.out.println("Dog guarding the house");
    }
}
```

```java
package com.testing.oop2.Polymorphic.DemoTest04;

public class Cat extends Animal {
    public void eat() {
        System.out.println("猫吃猫粮");
    }

    public void catchMouse() {
        System.out.println("Catch the mouse");
    }
}
```

```java
package com.testing.oop2.Polymorphic.DemoTest04;

public class DemoTest04 {
    public static void main(String[] args) {
        Animal d = new Dog();
        fn(d);
        Animal c = new Cat();
        fn(c);
        // 后续有继承子 Animal 的其他子类，都可以用这个方法，而不用重新声明一个函数。
    }

    // 形参指定父类类型，调用此方法时，实参可以接收继承自父类的任意子类对象。
    public static void fn(Animal a) {
        a.eat();
        // a.look();
        // 报错：无法解析 'Animal' 中的方法 'look'。无法使用子对象自身特有方法
        // a.catchMouse();
        // 报错：无法解析 'Animal' 中的方法 'catchMouse'。无法使用子对象自身特有方法
    }
}
```

## 2.3 多态中的转型

### 向上转型

父类引用指向子类对象，好比：`double num = 1`，小类型自动转大类型

```java
package com.testing.oop2.Polymorphic.DemoTest04;

public abstract class Animal {
    public abstract void eat();
}
```

```java
package com.testing.oop2.Polymorphic.DemoTest04;

public class Dog extends Animal {
    public void eat() {
        System.out.println("狗吃狗粮");
    }
}
```

```java
package com.testing.oop2.Polymorphic.DemoTest04;

public class Cat extends Animal {
    public void eat() {
        System.out.println("猫吃猫粮");
    }
}
```

```java
package com.testing.oop2.Polymorphic.DemoTest04;

public class DemoTest04 {
    public static void main(String[] args) {
        Animal d = new Dog(); // 这就是向上转型，小类型自动转大类型
    }
}
```

### 向下转型

向下转型类似类型强转，大类型强转小类型：

```java
父类类型 对象名1 = new 子类对象();
子类对象 对象名2 = (子类对象) 对象名1;
```

```java
package com.testing.oop2.Polymorphic.DemoTest05;

public abstract class Animal {
    public abstract void eat();
}
```

```java
package com.testing.oop2.Polymorphic.DemoTest05;

public class Dog extends Animal {
    public void eat() {
        System.out.println("狗吃狗粮");
    }

    public void look (){
        System.out.println("Dog guarding the house");
    }
}
```

```java
package com.testing.oop2.Polymorphic.DemoTest05;

public class DemoTest05 {
    public static void main(String[] args) {
        Animal a = new Dog();
        a.eat();
        // a.look(); // 报错：无法解析 'Animal' 中的方法 'look'
        Dog d = (Dog) a;
        d.look(); // 强转之后就能使用 Dog 自有的 look 方法。
    }
}

/*
狗吃狗粮
Dog guarding the house
*/
```

### 向下转型 - 类型转换异常 & `instanceof` 类型判断

当等号左右两边类型不一样时，就会出现类型转换异常 `ClassCastException`，如下：

```java
package com.testing.oop2.Polymorphic.DemoTest06;

public class DemoTest06_1 {
    public static void main(String[] args) {
        Animal06_1 d = new Dog06_1();
        fn(d);
        Animal06_1 c = new Cat06_1();
        fn(c);
        // 报错：class Cat06_1 cannot be cast to class Dog06_1
        // Cat06_1 和 Dog06_1 是平级的兄弟类，没有继承关系，无法强转
    }

    public static void fn(Animal06_1 a){
        a.eat();
        Dog06_1 d = (Dog06_1) a;
        d.look();
    }
}

abstract class Animal06_1 {
    public abstract void eat();
}

class Dog06_1 extends Animal06_1 {
    public void eat() {
        System.out.println("狗吃狗粮");
    }

    public void look() {
        System.out.println("Dog guarding the house");
    }
}

class Cat06_1 extends Animal06_1 {
    public void eat() {
        System.out.println("猫吃猫粮");
    }

    public void catchMouse() {
        System.out.println("Catch the mouse");
    }
}

/*
狗吃狗粮
Dog guarding the house
猫吃猫粮
Exception in thread "main" java.lang.ClassCastException: class com.testing.oop2.Polymorphic.DemoTest06.Cat06_1 cannot be cast to class com.testing.oop2.Polymorphic.DemoTest06.Dog06_1 (com.testing.oop2.Polymorphic.DemoTest06.Cat06_1 and com.testing.oop2.Polymorphic.DemoTest06.Dog06_1 are in unnamed module of loader 'app')
	at com.testing.oop2.Polymorphic.DemoTest06.DemoTest06_1.fn(DemoTest06_1.java:13)
	at com.testing.oop2.Polymorphic.DemoTest06.DemoTest06_1.main(DemoTest06_1.java:8)
*/
```

解决这个问题的关键：在向下转型之前，先通过 `instanceof` 判断类型，`instanceof` 的判断结果是布尔值：

```java
package com.testing.oop2.Polymorphic.DemoTest06;

public class DemoTest06_2 {
    public static void main(String[] args) {
        Animal06_2 d = new Dog06_2();
        fn(d);
        Animal06_2 c = new Cat06_2();
        fn(c);
    }

    public static void fn(Animal06_2 a) {
        a.eat();
        // 先通过 instanceof 判断类型再强转
        if (a instanceof Dog06_2 d) {
            // Java 16+ 的模式匹配语法，直接在 instanceof 里声明变量 d，如果 a 是 Dog06_2 类型，就会自动把 a 强转为 Dog06_2 并赋值给 d，就可以直接在 if 代码块里使用 d。
            d.look();
        }
        if (a instanceof Cat06_2) {
            Cat06_2 c = (Cat06_2) a;
            c.catchMouse();
        }

    }
}

abstract class Animal06_2 {
    public abstract void eat();
}

class Dog06_2 extends Animal06_2 {
    public void eat() {
        System.out.println("狗吃狗粮");
    }

    public void look() {
        System.out.println("Dog guarding the house");
    }
}

class Cat06_2 extends Animal06_2 {
    public void eat() {
        System.out.println("猫吃猫粮");
    }

    public void catchMouse() {
        System.out.println("Catch the mouse");
    }
}

/*
狗吃狗粮
Dog guarding the house
猫吃猫粮
Catch the mouse
*/
```

## 2.4 多态综合案例

定义一个 NoteBook 类，此类具备 start、stop 和 use USB 的功能。

具体是什么 USB，NoteBook 不关心，只要符合 USB 规范的设备都支持。

Mouse 和 Keyboard 要想在电脑上使用，就必须遵守 USB 规范，不然 Mouse 和 Keyboard 生产出来无法使用。

实现 NoteBook 类，以及实现 NoteBook 使用 Mouse 和 Keyboard，各个实现要求如下：

- USB 接口：包含 open 和 close 功能
- NoteBook 类：包含 start、stop、use USB 功能
- Mouse 类：符合 USB 规格
- Keyboard 类：符合 USB 规格

```java
package com.testing.oop2.Polymorphic.DemoTest07;

public interface USB {
    public abstract void open();
    public abstract void close();
}
```

```java
package com.testing.oop2.Polymorphic.DemoTest07;

public class Mouse implements USB {
    public void open() {
        System.out.println("开启鼠标");
    }

    public void close() {
        System.out.println("关闭鼠标");
    }

    public void click() {
        System.out.println("点击鼠标");
    }
}
```

```java
package com.testing.oop2.Polymorphic.DemoTest07;

public class Keyboard implements USB {
    public void open() {
        System.out.println("开启键盘");
    }

    public void close() {
        System.out.println("关闭键盘");
    }

    public void keydown() {
        System.out.println("按下键盘");
    }
}
```

```java
package com.testing.oop2.Polymorphic.DemoTest07;

public class NoteBook {
    public void start() {
        System.out.println("笔记本-开机！");
    }

    public void stop() {
        System.out.println("笔记本-关机！");
    }

    public void useUSB(USB usb) {
        usb.open();
        if (usb instanceof Mouse d1) {
            d1.click();
        } else if (usb instanceof Keyboard d2) {
            d2.keydown();
        }
        usb.close();
    }
}
```

```java
package com.testing.oop2.Polymorphic.DemoTest07;

public class DemoTest07 {
    public static void main(String[] args) {
        NoteBook nb = new NoteBook();
        Mouse m = new Mouse();
        nb.start();
        nb.useUSB(m);
        nb.stop();

        System.out.println("--------------");

        Keyboard k = new Keyboard();
        nb.start();
        nb.useUSB(k);
        nb.stop();
    }
}
```
